Tambah Sensor

Passhash disimpan terenkripsi di MySQL. Dapatkan passhash dari PRTG: Setup → Account Settings → My Account. Jika server PRTG sama dengan sensor yang sudah ada, kosongkan IP, Username, dan Passhash — cukup isi Label dan ID sensor.

Kosongkan untuk pakai username dari sensor yang sudah ada.

PRTG Monitoring

Atur Posisi

Seret kartu ke posisi baru (atau pakai tombol ◀ ▶ / tombol panah keyboard), lalu simpan layout. Urutan atas ke bawah dulu, baru lanjut kolom berikutnya sesuai kapasitas slot.

Lebih dari kapasitas = otomatis dibagi ke slide berikutnya, lalu berputar bergantian. Di layar tampil, tombol panah di tepi kiri/kanan layar memindahkan slide secara manual; putaran otomatis jalan lagi setelah jeda di atas tanpa klik.
