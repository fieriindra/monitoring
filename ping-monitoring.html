Tambah Perangkat

Password SSH disimpan terenkripsi di MySQL dan tidak pernah dikirim kembali ke browser.

Saat edit, kosongkan untuk tetap memakai password lama.
Otomatis disisipkan sebagai src-address= di setiap perintah ping MikroTik. Kosongkan jika tidak perlu.
Tiap baris jadi kolom terpisah di layar TAMPILKAN. Bisa tulis IP | Nama Kolom (atau cukup IP, lalu ubah nama tiap kolom langsung di menu ATUR POSISI).
Preset otomatis mengikuti tipe perangkat. Anda boleh mengubahnya manual.
